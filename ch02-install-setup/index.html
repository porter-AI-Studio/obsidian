第 2 章 · Part 1：認識 Obsidian：為什麼是它？

安裝與基本設定：從零開始的第一步

五分鐘完成安裝，建立你的第一個 Vault

Obsidian 是免費的嗎？

Obsidian 核心功能完全免費，個人與商業用途皆可使用，無需帳號登入。你的所有筆記以純 Markdown 格式儲存在本機，不被任何平台鎖定。

💡

免費同步替代方案：如果你需要跨裝置同步但不想付費，可以使用 iCloud（macOS/iOS）、Google Drive、Dropbox 等雲端硬碟，或開源的 Syncthing（適合進階使用者）。這些方案免費且運作良好，差別只是沒有官方的端對端加密保障。

下載 Obsidian

Obsidian 支援所有主流平台，前往官網下載對應版本即可：

下載地址：obsidian.md/download

支援平台：Windows、macOS、Linux、iOS、Android

Obsidian 沒有網頁版，必須安裝桌面應用程式。它的安裝非常單純：

Windows 安裝

下載 .exe 安裝檔，雙擊執行。程式會自動安裝並啟動，不需要任何管理員權限，也不會在你電腦裡寫入雜亂的設定檔，所有筆記和設定都可以打包帶走。

💡

Windows 安裝小技巧：如果你希望 Obsidian 成為可攜式應用程式（Portable App），可以下載 .zip 壓縮檔版本。解壓縮後直接執行 Obsidian.exe，所有設定都會保存在同一個資料夾中，非常適合放在 USB 隨身碟上使用。

macOS 安裝

下載 .dmg 檔案，雙擊打開，將 Obsidian 圖示拖曳到 Applications 資料夾中即可完成安裝。

⚠️

macOS 安全性提示：如果系統提示「無法打開 Obsidian，因為它來自未識別的開發者」，請前往「系統偏好設定 → 安全性與隱私權 → 一般」，點擊「仍要打開」按鈕。這是因為 Obsidian 未在 Apple Developer Program 中註冊，但軟體本身是安全的開源專案。

Linux 安裝

提供 .AppImage、.deb、.rpm 等多種封裝。以最通用的 AppImage 為例： 

# 給予執行權限
chmod +x Obsidian-*.AppImage

# 執行應用程式
./Obsidian-*.AppImage
ℹ️

Linux 套件管理員安裝：如果你使用 Arch Linux，可以透過 AUR 安裝：yay -S obsidian。Ubuntu/Debian 使用者可以直接安裝 .deb 套件，會自動處理相依性問題。

第一次開啟與建立你的第一個 Vault

第一次開啟 Obsidian，你會看到一個歡迎畫面，主要有三個選項：

  • 快速開始 (Quick Start)：在預設位置自動建立一個 Vault，讓你立即開始記筆記。
  • 建立新儲存庫 (Create new vault)：自訂名稱和存放路徑來建立一個全新儲存庫。
  • 開啟資料夾為儲存庫 (Open folder as vault)：如果你已經有 Markdown 筆記，可以直接把該資料夾在 Obsidian 中打開。

這裡我們選擇「建立新儲存庫」，填入儲存庫名稱（例如 My Knowledge Base），並點擊「瀏覽」選擇存在你電腦的哪個資料夾（例如 Documents/Obsidian）。點擊「建立」後，你專屬的知識儲存庫就誕生了。

💡

Vault 命名建議：建議使用英文名稱命名 Vault，避免在某些外掛或跨平台同步時出現編碼問題。例如用 knowledge-base 取代 知識庫。Vault 內部的筆記檔案名稱則可以使用中文，完全沒有問題。

認識介面：四大區域

進入 Vault 後，你會看到 Obsidian 的主介面。它分為四個主要區域：

1. Ribbon 工具列（最左側）

一排垂直圖示，由上到下依序是：

  • 🔍 快速切換（Ctrl/Cmd+O）：搜尋並開啟任何筆記
  • 🕸 關聯圖（Graph View）：視覺化整個知識網絡
  • 📅 今天的每日筆記
  • 📋 命令面板（Ctrl/Cmd+P）：執行所有可用指令
  • ⚙️ 設定
💡

Ribbon 自訂技巧：安裝社群外掛後，許多外掛會自動在 Ribbon 工具列新增圖示。如果覺得太擁擠，可以在設定中調整「外觀 → Ribbon 工具列」來隱藏不常用的圖示，保持介面簡潔。

2. 左側面板 (File Explorer)

顯示 Vault 裡所有的資料夾和筆記。點擊資料夾可展開，點擊筆記可開啟。你也可以在這裡用右鍵新增資料夾、重新命名、或刪除檔案。

3. 中央編輯區

主要工作區域。Obsidian 預設為「即時預覽」模式——你輸入 Markdown 語法的同時看到渲染結果，不需要手動切換。你也可以切換到「原始碼模式」查看純 Markdown 文字。

中央區域支援分割視窗——在右上角選單選擇「向右分割」，可同時開啟兩份筆記並排查看。

4. 右側面板

預設顯示「反向連結」（Backlinks）和「標籤」——哪些筆記連結到了目前這則，以及這則筆記有哪些標籤。這個面板在你的知識網絡越來越大之後會變得非常有用。

必要的基本設定

點擊左下角齒輪圖示（或按 Ctrl/Cmd+,）進入設定。以下幾項建議第一次就設定好：

切換介面語言

前往「設定 → 關於 → 語言」，選擇「繁體中文」，重啟 Obsidian 後生效。

ℹ️

語言切換注意事項：切換語言後，部分社群外掛的設定介面可能仍維持英文，這是因為外掛開發者尚未提供繁體中文翻譯，屬於正常現象，不影響功能使用。

設定新筆記的預設位置

前往「設定 → 檔案與連結 → 新筆記的預設位置」。推薦選擇「目前資料夾」或指定一個 inbox 資料夾（例如 00-Inbox），避免新筆記散落在 Vault 根目錄。

設定附件儲存位置

前往「設定 → 檔案與連結 → 附件資料夾路徑」，指定一個專門放圖片和附件的資料夾（例如 Assets）。這樣你貼進去的截圖和圖片會自動存放到對應位置，Vault 才不會亂。

開啟「使用 [[Wikilinks]]」

前往「設定 → 檔案與連結」，確認「使用 [[Wikilinks]]」已開啟。這是 Obsidian 雙向連結的語法基礎，建議保持開啟狀態。

Vault 的資料夾結構

Vault 內部就是你電腦上的普通資料夾，你可以直接在檔案總管裡查看。一個剛建立的 Vault 大概長這樣： 

My Knowledge Base/          ← 你的 Vault 根目錄
├── .obsidian/              ← Obsidian 的設定資料夾（隱藏）
│   ├── app.json            ← 應用程式設定
│   ├── appearance.json     ← 外觀設定
│   ├── community-plugins.json
│   └── plugins/            ← 安裝的外掛
└── (你的筆記 .md 檔案)

.obsidian 資料夾由 Obsidian 自動管理，存放這個 Vault 專屬的偏好設定、快速鍵、佈景主題和外掛。不同的 Vault 有各自獨立的 .obsidian 設定，互不干擾。

💡

建議加入 .obsidian 到 Git：如果你使用 Git 管理 Vault，建議將 .obsidian 資料夾一起加入版本控制。這樣換了電腦或重裝系統，所有的設定、外掛、快速鍵都能一鍵還原。

多個 Vault：你可以建立多個 Vault，例如一個放工作筆記、一個放個人學習。在 Obsidian 左下角點擊 Vault 圖示可以切換。Vault 之間的筆記是完全隔離的，內部連結只在同一個 Vault 內有效。

建立第一則筆記

一切都設定好了，現在建立第一則筆記試試： 

# 我的第一則筆記

今天開始用 Obsidian 管理知識！

## 我想用它來做什麼

- 整理閱讀心得
- 記錄工作上學到的技術
- 連結不同主題的想法

## 相關筆記

- [[我的閱讀清單]]
- [[工作筆記]]

輸入 [[我的閱讀清單]] 時，Obsidian 會提示你可以建立一則新筆記。按 Enter 確認，這個連結就建立了——即使那則筆記還不存在，Obsidian 也會幫你把它記下來，等你之後建立。

⚠️

連結斷裂的處理方式：如果你重新命名或移動了筆記檔案，Obsidian 會自動更新所有指向該筆記的內部連結。但如果透過作業系統的檔案總管直接移動或重新命名檔案，連結就會斷裂。建議一律在 Obsidian 內部進行檔案操作，或安裝「File Explorer Note Title」外掛來輔助管理。

進階設定：外觀與佈景主題

除了基本設定，Obsidian 也提供豐富的外觀自訂選項，讓你的筆記環境更符合個人喜好：

切換深色/淺色模式

前往「設定 → 外觀 → 主題」，可以選擇「淺色」、「深色」或「跟隨系統」。建議開啟「跟隨系統」，讓 Obsidian 自動根據你的作業系統設定切換。

安裝社群佈景主題

在「設定 → 外觀 → 主題」中點擊「管理」，可以瀏覽社群提供的數百種佈景主題。熱門主題包括：

  • Minimal：簡潔現代，高度可自訂
  • Blue Topaz：台灣開發者製作，功能豐富
  • Things：靈感來自 Things 3 的設計風格
  • AnuPpuccin：色彩柔和，閱讀體驗極佳
💡

佈景主題切換建議：建議先使用預設主題熟悉基本操作，等使用一週後再嘗試更換佈景主題。過早更換主題可能會因為介面變化而增加學習曲線。

常見問題與疑難排解

安裝後無法啟動

如果你在安裝後點擊圖示卻沒有反應，請嘗試以下步驟：

  1. 確認你的作業系統版本是否符合最低需求（Windows 10+、macOS 10.13+、Linux 支援 x86_64 架構）
  2. 重新下載安裝檔，可能檔案在下載過程中損毀
  3. 檢查防毒軟體是否阻擋了 Obsidian 的執行
  4. 在終端機中執行 Obsidian，查看錯誤訊息

Vault 無法開啟

如果 Vault 資料夾中的 .obsidian 設定檔損毀，可能會導致無法開啟。解決方法：

  1. 備份你的筆記檔案（.md 檔案）
  2. 刪除 Vault 中的 .obsidian 資料夾
  3. 重新在 Obsidian 中開啟該資料夾，系統會自動建立全新的設定檔
⚠️

重要提醒：刪除 .obsidian 資料夾會遺失所有自訂設定、快速鍵、已安裝的外掛和佈景主題。但你的筆記內容（.md 檔案）完全不受影響。建議定期備份整個 Vault 資料夾。

中文輸入法問題

部分使用者在 Obsidian 中遇到中文輸入法無法正常運作的問題，通常是因為：

  • Windows 使用者：確認輸入法切換為「微軟注音」或「微軟倉頡」
  • macOS 使用者：嘗試切換到「繁體拼音」或「倉頡」輸入法
  • Linux 使用者：確認 fcitx5 或 ibus 輸入法框架已正確設定

最佳實踐建議

💡

新手最佳實踐：

  • 先求有，再求好：第一週先專注於建立筆記習慣，不要急著安裝外掛或調整設定
  • 每天寫一則筆記：即使只是簡單的日記或想法記錄，持續使用比完美設定更重要
  • 善用每日筆記：開啟每日筆記功能，讓 Obsidian 自動為你建立每天的記錄頁面
  • 建立連結習慣：每則新筆記至少連結到一則現有筆記，逐步建立你的知識網絡

新手必裝的 4 個初始外掛

雖然建議先用原生功能熟悉 Obsidian 一到兩週，但以下 4 個外掛幾乎每位使用者都需要，越早安裝越省心：

安裝外掛的方式

  1. 前往「設定 → 社群外掛 → 瀏覽」
  2. 搜尋外掛名稱（例如 Custom Attachment Location）
  3. 點擊「安裝」，安裝完畢後記得點擊「啟用」
⚠️

安全性提醒：安裝社群外掛前，請先確認「設定 → 社群外掛 → 關閉安全模式」已開啟（Obsidian 預設關閉社群外掛）。建議只安裝下載量大、有定期更新的外掛，並定期到「已安裝外掛」頁面點擊「更新全部」。

Custom Attachment Location 設定建議

安裝後，前往「設定 → Custom Attachment Location」，推薦設定為：{notedir}/assets。這樣每則筆記的圖片都會自動放到同一資料夾內的 assets 子目錄，結構清晰，移動筆記時圖片不會失連。

Local Backup 設定建議

安裝 Local Backup 後，建議設定：

  • 備份路徑：指定到 Vault 外部的資料夾（例如 D:\ObsidianBackup）
  • 備份頻率：每天一次自動備份
  • 保留版本數：至少 7 個（保留一週的歷史）
