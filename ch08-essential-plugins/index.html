第 8 章 · Part 3：插件生態：讓 Obsidian 變成你的超級工具

必裝插件 Top 10：新手必知清單

10 個插件，解決 10 個真實的使用痛點

從空白到超級工具，只差這幾個插件

剛安裝好 Obsidian 的人，通常會在第一個星期遇到一些讓人不舒服的摩擦：月曆在哪裡？為什麼一次只能看一則筆記？模板功能怎麼這麼陽春？URL 貼進去怎麼還要自己加標題？

這些痛點幾乎都有對應的插件可以解決。Obsidian 的社群插件庫目前超過 1,500 個，但新手不需要從頭篩選——大多數人用了幾年後，核心常備的不過 10~15 個。這一章幫你省去這段摸索期。

在進入清單之前，先花兩分鐘了解怎麼安裝插件。

如何安裝社群插件

Obsidian 預設開啟「安全模式」，會阻止社群插件運行。第一步是關閉它，然後進入插件瀏覽器： 

安裝社群插件的步驟：

1. 設定（齒輪圖示）→ 社群插件
2. 點擊「關閉安全模式」
3. 點擊「瀏覽」進入插件市集
4. 搜尋插件名稱
5. 點擊「安裝」→「啟用」

💡 已安裝的插件可在「已安裝插件」清單中管理，
   可以個別啟用/停用，不需要解除安裝。

安全模式的用途：社群插件是由第三方開發者維護的 JavaScript 程式碼，理論上可以存取你的檔案系統。Obsidian 預設開啟安全模式是合理的防護機制。本章介紹的插件都是社群廣泛使用、長期維護的知名插件，安全性有保障。

必裝 Top 10 核心矩陣

1. Calendar — 月曆視圖與快速建立 Daily Note

如果你使用 Daily Notes（每日筆記），Calendar 幾乎是第一個要裝的插件。它在右側邊欄新增一個月曆介面，讓你用「月」的視角瀏覽所有 Daily Notes，點擊任一天就能快速建立或開啟那天的筆記。

更實用的是，Calendar 支援在月曆上顯示「週筆記（Weekly Note）」的入口——每週固定做一次回顧，這是 LYT 系統的核心習慣（見 ch07）。

適合誰：任何使用 Daily Notes 的人，幾乎必裝。
難度：⭐（安裝後即可使用，無需額外設定）

2. Templater — 模板自動化的神器

Obsidian 內建的 Templates 核心插件只能做靜態插入，而 Templater 讓模板「活起來」：可以抓取系統當前時間、自動填入日期、從檔案名稱動態生成內容，甚至執行 JavaScript 腳本。

最常見的用法是建立 Daily Note 模板：每次新增當天筆記時，自動帶入日期、星期幾、本週週數，並預設好你習慣的區塊結構（早上待辦、會議記錄、想法速記）。 

# Templater Daily Note 模板範例

---
date: <% tp.date.now("YYYY-MM-DD") %>
week: W<% tp.date.now("WW") %>
day: <% tp.date.now("dddd") %>
---

## 今日待辦
- [ ]

## 會議記錄

## 想法速記

## 回顧
> 今天最重要的一件事：

適合誰：有固定筆記習慣、想減少重複操作的人。
難度：⭐⭐⭐（基礎用法簡單，進階腳本需要學習）

3. Hover Editor — 浮動視窗多工編輯

Obsidian 長期被詬病的一個問題：要同時瀏覽多則筆記，只能靠分割面板，版面很快就擠滿了。Hover Editor 解決了這個問題——當你把滑鼠移到任何 [[內部連結]] 上方，會彈出一個可自由拖曳的浮動視窗，而且可以在浮動視窗裡直接編輯，不需要開啟新分頁。

這讓「參考 A 筆記同時編輯 B 筆記」變得自然，是提升多工效率最明顯的插件之一。

適合誰：頻繁在多則筆記之間參照、編輯的人。
難度：⭐⭐（開箱即用，進階設定可調整視窗行為）

4. Style Settings — 介面外觀自訂

Obsidian 的主題系統提供了視覺上的差異化，而 Style Settings 則讓你在主題基礎上進一步微調：字體大小、標題顏色、行距、背景透明度……這些都不需要寫 CSS，只需在設定介面用滑鼠調整。

Style Settings 本身不改變任何視覺——它需要搭配支援它的主題（例如 Minimal、AnuPpuccin）才能發揮作用。安裝 Style Settings 後，在「設定 → Style Settings」裡就能看到對應主題提供的所有可調選項。

適合誰：在意介面美觀、想要客製化外觀但不懂 CSS 的人。
難度：⭐⭐⭐（依賴主題，不同主題選項差異很大）

5. Excalidraw — 手繪風格視覺筆記

Excalidraw 是一款開源的線上繪圖工具，而 Obsidian 的 Excalidraw 插件把它完整整合進 Vault——你可以在筆記裡直接建立手繪風格的圖表、流程圖、思維導圖，而且圖形節點可以連結到其他筆記（就像 [[wikilink]] 一樣）。

進階用法中，Excalidraw 可以從一份清單自動生成樹狀圖，或是替你把某則筆記的關聯圖畫成靜態的可視化圖表——比 Graph View 更穩定、更可閱讀。

適合誰：喜歡用圖表思考、需要視覺化整理概念的人。
難度：⭐⭐⭐⭐（功能非常豐富，需要一些時間摸索）

6. Dataview — 把 Vault 變成可查詢的資料庫

Dataview 是 Obsidian 插件生態裡功能最強大的之一。它讓你用類 SQL 的查詢語法，從 Vault 裡動態提取符合條件的筆記、生成表格或清單。

例如：「列出所有標有 #閱讀筆記 且 重要性 大於 3 的筆記，按建立日期排序」——這在 Dataview 裡只需要幾行語法。 

```dataview
TABLE title, 重要性, created
FROM #閱讀筆記
WHERE 重要性 >= "⭐⭐⭐"
SORT created DESC
```

Dataview 是 ch09 的主角，這裡先點到為止：只要你有使用 Metadata（Properties），就值得安裝 Dataview。

適合誰：有系統地使用 Metadata、想要動態彙整筆記的人。
難度：⭐⭐⭐⭐（語法需要學習，但基礎查詢不難）

7. Obsidian Git — 自動備份到 GitHub

Vault 裡的資料全部存在本機，代表硬碟壞了就什麼都沒了。Obsidian Git 插件讓你把 Vault 連結到 GitHub 倉庫，可以設定每隔幾分鐘自動 commit + push，完全不需要手動操作。

這同時解決了「版本控制」的問題——你可以查看任意一則筆記的修改歷程，也可以回滾到特定版本。對於把重要知識存進 Vault 的人，這是不可或缺的安全網。

適合誰：有一定筆記量、想要可靠備份的人（需要基本 Git 知識）。
難度：⭐⭐⭐（需要先設定好 Git 和 GitHub，之後自動運行）

8. Auto Link Title — 貼 URL 自動抓取標題

這個插件解決一個小但頻繁的痛點：你在筆記裡貼上一個網址，想要讓它變成 Markdown 超連結格式 [標題](URL)，但還要自己查標題再手動填入。

安裝 Auto Link Title 後，直接貼上 URL，插件會自動請求該網址、抓取頁面標題，自動幫你組合成 [標題](URL) 格式。不需要任何設定，安裝即用。

適合誰：習慣在筆記裡收藏網頁連結的人。
難度：⭐（安裝後完全自動）

9. Outliner — 大綱模式強化

Obsidian 的列表操作預設很基本：縮排、移動項目、折疊子項目都需要用鍵盤快捷鍵配合 Tab 鍵。Outliner 讓大綱操作更接近 Roam Research 或 Logseq 的體驗：

  • 按住 Alt + 上下方向鍵：移動整個列表項目（含子項目）
  • 按 Tab / Shift+Tab：縮排/取消縮排（行為更直觀）
  • 折疊/展開大綱層級更順手

適合誰：喜歡用大綱式結構整理想法的人。
難度：⭐（安裝後立刻生效）

10. Editing Toolbar — 富文字工具列

如果你不熟悉 Markdown 語法，Editing Toolbar 在編輯器頂部新增一排類 Word 的格式工具列：粗體、斜體、標題層級、程式碼、連結、表格——點擊按鈕就能插入對應格式，不需要記憶語法。

對於已熟悉 Markdown 的人，這個插件可以不裝；但如果你正在把其他人引入 Obsidian（例如不懂 Markdown 的同事），這是降低進入門檻的好幫手。

適合誰：不熟悉 Markdown 的新手，或需要帶領非技術用戶使用 Obsidian 的人。
難度：⭐（安裝後立刻出現工具列）

插件選擇哲學：少即是多。每一個插件都在 Obsidian 啟動時載入、佔用記憶體、可能和其他插件衝突。新手常見的錯誤是一口氣安裝 30 個插件，然後發現介面變慢、設定項目爆炸。建議的方式：先只裝前 3 個（Calendar、Templater、Hover Editor），用一個月後再根據自己的真實痛點逐步增加。

延伸外掛：任務管理的進階選項

Top 10 清單聚焦在普遍適用的核心插件。但如果你的 Obsidian 使用場景以「任務追蹤」或「專案管理」為主，以下三個插件值得特別認識——它們構成了 Obsidian 任務管理的完整光譜，從輕量到全功能都有對應選擇。

Tasks — 跨筆記的任務彙整

Tasks 讓你把散落在 Vault 各處的 - [ ] checkbox 全部統一管理。你可以設定截止日期、重複週期、優先順序，然後用一個查詢語法把所有「今天到期」的任務集中顯示在同一個地方——不論它們原本在哪一則筆記裡。 

```tasks
not done
due today
sort by priority
```

-- 這段查詢會列出 Vault 中所有今天到期的未完成任務 --

Tasks 的核心概念是：任務不屬於清單，任務屬於知識庫。一個任務可以在會議筆記裡建立、在每日筆記裡追蹤、在 Dashboard 裡彙整——只要它是個 checkbox，Tasks 就能找到它。

適合誰：有大量跨筆記任務、需要統一追蹤截止日的人。
難度：⭐⭐⭐（查詢語法需要學習，但功能非常強大）

Kanban — 視覺化看板管理

Kanban 在 Obsidian 裡新增一種「看板視圖」的筆記類型：你可以建立 Trello 風格的卡片欄位（待辦 / 進行中 / 完成），每張卡片都是一則獨立的 Obsidian 筆記，可以包含連結、標籤、附件。

與其他看板工具不同的是，Kanban 的資料完全儲存為 Markdown 格式——這意味著你可以直接用文字編輯器看到所有卡片內容，也可以用 Dataview 查詢卡片的元資料。

適合誰：習慣看板工作流（Scrum、Kanban）的人、專案管理需求較重的用戶。
難度：⭐⭐（視覺化介面直觀，但進階設定需要摸索）

Tasks vs Kanban 怎麼選？ Tasks 強在「時間維度」——追蹤截止日期、重複任務、優先順序；Kanban 強在「狀態維度」——追蹤任務在流程中的位置（設計中 → 開發中 → 測試 → 完成）。複雜專案可以兩者並用：用 Kanban 管理階段，用 Tasks 管理每個階段裡的具體待辦事項。

QuickAdd — 閃念捕捉與自動化觸發器

QuickAdd 解決一個非常具體的問題：當你正在做某件事，突然冒出一個想法或任務，你希望用最少的步驟把它記錄下來，而不是打斷當前工作流去手動建立筆記。

QuickAdd 讓你設定多個「快速指令」，每個指令可以綁定一個快捷鍵：按下快捷鍵 → 彈出輸入框 → 輸入內容 → 自動依設定規則建立筆記（或附加到指定筆記的特定區塊）。整個過程不超過 3 秒。 

QuickAdd 常見用法範例：

1. 「閃念捕捉」模式
   快捷鍵 Alt+Q → 輸入想法 → 自動加到 Inbox.md 末尾

2. 「快速書籍筆記」模式
   快捷鍵 Alt+B → 輸入書名、作者 → 自動建立帶模板的書籍筆記

3. 「每日待辦追加」模式
   快捷鍵 Alt+T → 輸入任務 → 自動加到今天的 Daily Note

QuickAdd 也可以和 Templater 深度整合：QuickAdd 提供「觸發入口」，Templater 提供「模板邏輯」，兩者合作可以建立非常精密的自動化工作流。

適合誰：想要快速捕捉靈感、降低「記錄摩擦力」的人。
難度：⭐⭐⭐（基本設定 10 分鐘可完成，進階 Macro 需要時間）

插件生態系全局視圖

Obsidian 的 1,500+ 個插件，可以用四個象限來理解它的生態系結構。這不是嚴格的分類，而是幫助你找到自己所需要的插件在哪個方向。

如何使用這張圖：左上角的「生產力 & 自動化」是大多數人的第一優先區；如果你的主要需求是任務管理，從右下角的「任務 & 專案管理」開始；如果你重視視覺化思考，右上角的「視覺化 & 介面」值得深入。左下角的「知識管理 & 查詢」是進階使用者的舞台，需要有一定的筆記量才能發揮效益。

依需求選插件：決策流程圖

不確定自己需要哪個插件？以下的決策流程圖依三個核心問題引導你找到最適合的起始配置。

插件組合搭配建議

單一插件能解決單一問題，但真正的威力在於「組合搭配」——當兩個插件各自管理不同維度，再共享同一份資料時，工作流就會產生「乘數效應」。以下四種組合是社群中最常見、效果最顯著的配置。

組合一詳解：Templater + Dataview 自動化資料庫

這是最具代表性的組合。核心概念是「輸入有格式，查詢才有效」：

  1. 用 Templater 建立標準化模板（每本書的筆記都有 author、rating、status 等固定欄位）
  2. 每次新增筆記時，模板自動帶入這些欄位，只需填入內容
  3. 用 Dataview 建立動態 Dashboard，自動把所有書籍筆記按評分排序、依狀態分類

一旦這個循環建立起來，你的 Vault 就變成了一個可以自我彙整的知識資料庫——不需要手動整理，新增的內容自動出現在正確的地方。

進階技巧：在 Templater 模板中使用 tp.system.prompt() 讓使用者在建立筆記時互動輸入關鍵欄位，再由 Dataview 依這些欄位動態分類。這個模式可以應用在書籍筆記、論文摘要、會議記錄、聯絡人管理等各種場景。

組合二詳解：Calendar + Tasks 時間軸任務流

這個組合的本質是「把任務錨定在時間上」。每一個任務不再是抽象的待辦事項，而是有明確截止日的承諾： 

# 2026-07-02 Daily Note

## 今日任務
- [ ] 完成季報草稿 📅 2026-07-02 #工作
- [ ] 回覆 Porter 的 PR 意見 📅 2026-07-02 #開發
- [ ] 閱讀《原子習慣》第三章 📅 2026-07-03 #個人

## 筆記...

Tasks 插件會自動識別上面帶有 📅 日期標記的 checkbox，並在任何你想要的筆記裡（例如每週回顧頁）用查詢語法彙整所有即將到期的任務。Calendar 則提供月曆視角，讓你一眼看出哪幾天的任務較重。

插件效能與衝突注意事項

插件越裝越多，有一些常見的問題需要提前了解，避免日後浪費時間排查。

效能影響

以下幾個插件對效能的影響相對較大，在大型 Vault（超過 1,000 則筆記）時可能感受到啟動變慢或搜尋延遲：

  • Dataview：需要索引整個 Vault 的 metadata，Vault 越大索引時間越長。開啟後台更新可減輕感知延遲。
  • Smart Connections / Copilot：AI 語意搜尋插件需要在本地或雲端計算 embedding，首次啟用時會有明顯延遲。
  • Excalidraw：複雜的繪圖檔案載入較慢，建議不要把太多大型 Excalidraw 檔案放在常用資料夾。
  • Obsidian Git：設定自動 commit 頻率時，建議不要低於 10 分鐘一次，太頻繁的 commit 操作可能干擾編輯體驗。

常見衝突情境

Templater 與官方 Templates 核心插件並存：如果同時啟用兩者，可能導致模板插入行為衝突。建議：啟用 Templater 後，可以直接停用官方 Templates 核心插件，因為 Templater 包含了所有官方 Templates 的功能，再加上更多進階能力。

Tasks 與 Dataview 的任務顯示重疊：Dataview 也可以用 TASK 查詢顯示任務清單，與 Tasks 插件的顯示邏輯不完全相同。建議：選擇一個作為任務查詢的主要工具（通常 Tasks 更適合任務管理，Dataview 更適合資料統計），避免在同一個地方混用兩種查詢語法。

插件效能最佳化設定建議：

Dataview
  → 設定 > Dataview > Refresh Interval: 5000ms（預設 500ms 太頻繁）
  → 關閉不需要的 Inline Query 功能

Obsidian Git
  → Auto Commit Interval: 15 分鐘（不要低於 5 分鐘）
  → 啟用 "Pull on Startup" 以確保多裝置同步

Excalidraw
  → 設定 Export padding: 10（減少不必要的留白計算）
  → 使用 .excalidraw.md 格式而非 .excalidraw（更易被 Dataview 索引）

小結

這 10 個插件覆蓋了新手最常遇到的使用瓶頸：日常工作流（Calendar、Templater）、多工效率（Hover Editor）、介面美觀（Style Settings）、視覺思考（Excalidraw）、資料查詢（Dataview）、備份安全（Obsidian Git）、以及小而美的便利工具（Auto Link Title、Outliner、Editing Toolbar）。

其中，Dataview 因為功能複雜且可以做的事情太多，值得用整個章節來介紹。下一章我們從基礎語法開始，帶你寫出第一個 Dataview 查詢——讓分散在 Vault 各處的筆記，自動彙整到你需要的地方。
